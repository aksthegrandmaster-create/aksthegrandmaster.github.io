Featured Code Reference

Simple Arduino microcontroller code template to read an analog sensor pin layout:

// Define the analog pin connected to your sensor
const int sensorPin = A0; 
int sensorValue = 0;

void setup() {
  Serial.begin(9600); // Open serial communications
}

void loop() {
  sensorValue = analogRead(sensorPin); // Fetch sensor data
  Serial.println(sensorValue);
  delay(500); // Wait 500ms before reading again
}
